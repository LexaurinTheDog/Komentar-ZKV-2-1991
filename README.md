# Komentář k zákonu č. 2/1991 Sb., o kolektivním vyjednávání

Otevřený komentář k zákonu o kolektivním vyjednávání (ZKV) — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; kolektivní smlouvy podnikové a vyššího stupně, rozšíření závaznosti, kolektivní spory, zprostředkovatel a rozhodce, stávka a výluka.
